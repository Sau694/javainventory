# Inventory Management System

A dynamic Java Web Application designed for managing product inventory, categories, and stock details. Built using Java Servlets, JSP, and MySQL database.

## 🚀 Features
- **Product Management:** Add, update, view, and delete inventory items.
- **Database Integration:** Persistent storage with MySQL database.
- **MVC Architecture:** Structured code separating Controllers, DAOs, and Views.

## 🛠️ Tech Stack
- **Java (Servlets & JSP)**
- **MySQL Database**
- **HTML5 / CSS3**
- **Apache Tomcat Server**
